# 機械エラーコード管理

機械のエラーコードをブラウザ内の IndexedDB で管理し、Google Drive の `MachineErrorCodeDB-latest.json` と明示的に同期する Web アプリです。エラーコードは数値変換せず文字列で保持するため、`0012` や `AL-E01` もそのまま保存できます。

## 主な機能

- シリーズ（SRC350 / HU300）と型式（SRC350-M2 / HU300-M3）を切り替え、機種ごとに独立して管理
- 一覧、新規登録、編集、削除、全文キーワード検索
- 分類・タイプ・レベル・クラスでの絞り込み
- Excel（`.xlsx`）/ CSV のインポート、Excelのエクスポート、インポート用Excelフォーマットのダウンロード
- IndexedDB へのローカル保存
- Google OAuth ログインと Google Drive 上の JSON の取得・保存
- Drive 保存直前の `modifiedTime` 比較による競合上書き防止

## ローカルで起動

Node.js 20 以降を推奨します。

```bash
npm install
cp .env.example .env.local
# .env.local の VITE_GOOGLE_CLIENT_ID を設定
npm run dev
```

表示された URL（通常 `http://localhost:5173`）を開きます。Google 連携を使わない機能は Client ID 未設定でも利用できます。本番相当の確認は `npm run build && npm run preview` です。

## Google Drive API の設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成します。
2. **API とサービス > ライブラリ** で **Google Drive API** を有効化します。
3. **OAuth 同意画面**を設定します。テスト運用中は利用者をテストユーザーへ追加します。
4. **認証情報を作成 > OAuth クライアント ID > ウェブ アプリケーション** を選択します。
5. 「承認済みの JavaScript 生成元」に `http://localhost:5173` と本番 URL（例: `https://your-app.vercel.app`）を追加します。このトークン方式ではリダイレクト URI は不要です。
6. 発行された**クライアント ID**を `VITE_GOOGLE_CLIENT_ID` に設定します。OAuth クライアントシークレットや API キーはフロントエンドに置かないでください。

要求するスコープは `drive.file` です。初回の「クラウドへ保存」でマイドライブ直下に `MachineErrorCodeDB-latest.json` を作成します。

## 同期の仕様

- 通常の一覧・検索・編集は IndexedDB のデータを利用します。SRC350-M2 と HU300-M3 のデータはシリーズ・型式で分離され、画面切り替え時に混在しません。既存データは SRC350 / SRC350-M2 として引き継がれ、HU300 / HU300-M3 は0件から登録します。
- Drive上では両機種を1つのJSONに保持するため、クラウド同期で片方の機種が消えることはありません。Excel / CSV の入出力は現在選択中の機種だけが対象です。
- **クラウドから取得**は Drive の JSON をローカルデータに置き換え、ファイル ID と更新日時を IndexedDB に記録します。
- **クラウドへ保存**は保存直前に Drive の `modifiedTime` を取得します。最後に取得・保存した時刻と異なる場合、他端末で更新されたものと判断して保存を中止します。先にクラウドから取得してください。
- 同期履歴がない状態で同名ファイルが存在する場合も上書きを中止し、先に取得するよう案内します。同名ファイルを複数作らない運用を推奨します。

> ブラウザデータを消去すると同期情報も消えます。別 PC で初めて使うときは、必ず先に「クラウドから取得」してください。

## Vercel へのデプロイと環境変数

1. リポジトリを Vercel に Import します。Build Command は `npm run build`、Output Directory は `dist` です。
2. **Project Settings > Environment Variables** に以下を追加します。

   | Name | Value | Environment |
   |---|---|---|
   | `VITE_GOOGLE_CLIENT_ID` | Google Cloud の OAuth Client ID | Production / Preview / Development |

3. 再デプロイし、Vercel ドメインを Google Cloud の「承認済みの JavaScript 生成元」に追加します。Preview ごとに Google ログインを使う場合は各生成元も登録します。

`VITE_` 変数はブラウザへ公開されます。公開可能な OAuth Client ID のみ設定し、**クライアントシークレット、サービスアカウント鍵、アクセストークンは絶対に登録・コミットしないでください**。

## インポート形式

画面の「インポート用Excelフォーマット」から雛形をダウンロードできます。先頭シートの先頭行に以下の日本語ヘッダーを使用します（列順は任意）。CSVを読み込む場合はUTF-8を推奨します。

`エラーコード, 名称, 分類, タイプ, レベル, クラス, 異常内容, 調査内容, 復旧方法, Retry`

Excel の先頭ゼロを確実に維持するには、エラーコード列のセル書式を「文字列」にしてください。アプリは読込後の表示値を文字列として保存します。CSV出力には対応していません。

### 読み込みルール

- 「Excel / CSV取込」を押すとポップアップが開き、ファイル選択またはドラッグ＆ドロップで読み込めます。
- 取り込み前に「シリーズ共通データ」または「型式固有データ」を選択します。シリーズ共通データは選択シリーズの全型式に表示され、型式固有データは選択中の型式だけに表示されます。
- エラーコードを照合キーとし、選択した登録範囲内のデータだけを対象にします。他のシリーズ・型式・登録範囲のデータは変更しません。
- 一致するエラーコードは読み込んだ行の内容で更新します。空欄セルも空文字として上書きします。
- 一致しないエラーコードは新規登録します。エラーコードが空の行は読み飛ばします。
- ファイル内に同じエラーコードが複数ある場合は、後にある行を採用します。定義されていない列は無視します。
- 「エラーコード」列がないファイルは読み込まず、エラーを表示します。
